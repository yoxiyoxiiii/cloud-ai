### F4 角色列表页

### F5 RoleFormDialog（新增/编辑弹窗）

- 文件：`cloud-web/src/views/system/role/components/RoleFormDialog.vue`（新建，对照 UserFormDialog）
- 内容（设计 §4.1）：
  - props `{ modelValue, mode: 'add' | 'edit', role?: SysRoleVo }`；emits `update:modelValue` / `success`
  - 字段：name（必填 1-30）/ roleKey（必填，pattern `^[a-zA-Z][a-zA-Z0-9_-]{0,29}$`，前端约定兜底）/ status（radio 绑定 STATUS_NORMAL/STATUS_DISABLED 常量）
  - 打开时 watch 初始化：edit 回显三字段（**全部可编辑，roleKey 不锁定**——契约 §4.4 与用户 account 的差异点）；add 置默认；先 clearValidate
  - 提交：validate → add 走 `createRole`（toast"新增成功"）/ edit 走 `updateRole`（toast"保存成功"）→ emit success + 关闭；catch 留空（3003 由拦截器 toast，弹窗不关）；loading 防重
- 验收：空提交出必填错误且 0 请求；重复 roleKey 提交后错误 toast 出现、弹窗仍开；编辑保存后行内字段/状态 tag 更新

### F6 AssignMenuDialog（分配权限弹窗）

- 文件：`cloud-web/src/views/system/role/components/AssignMenuDialog.vue`（新建，对照 AssignRoleDialog）
- 内容（设计 §4.2 + D2 技术要点）：
  - props `{ modelValue, role?: SysRoleVo }`；emits `update:modelValue` / `success`；标题 `分配权限（{role.name}）`
  - 打开时 `Promise.all([menuTree(), listRoleMenuIds(role.id)])`；loading 包裹
  - `el-tree`：`node-key="id"` `show-checkbox` `default-expand-all` `:props="{ label: 'name', children: 'children' }"`；容器 max-height 360 overflow auto；自定义节点 slot：name + type==='F' 时追加 perms 灰字
  - **回显：`collectLeafIds` 收集叶子 → `await nextTick()` → `setCheckedKeys(已绑 id 过滤叶子)`**（传父 id 会误勾整棵子树）
  - **提交：`getCheckedKeys() ∪ getHalfCheckedKeys()` → `map(String)` → `assignRoleMenus`**（半选父也入库）；toast"分配成功" → emit success + 关闭；catch 留空；saving 防重
  - 树空/加载失败：el-empty 占位，弹窗可关闭
- 验收：勾选父节点子级联动；保存后重开勾选一致（父呈半选/全选）；全不勾保存后重开为空；admin 角色打开能正确回显（存量父目录绑定不误勾整树——叶子过滤的效果）

## 移交备忘（下一阶段规划前必读）

1. **删除角色无后端保护**：admin 种子超管可被删且即时解绑（契约 §7.7）——前端已加强确认文案但未拦截。**主控裁定（2026-10-06，规格审查）**：本任务不纳入后端改动，保持纯前端轨道；「内置角色保护」立项为后续独立后端任务（改行为+契约 §4.5，届时走 /dev-backend 出 3008 段错误码）
2. **分页无搜索参数**：/role/page 与 /user/page 同缺口（契约现状）；后端补过滤参数时先改契约再上前端搜索框
3. **name/status 后端无校验**（契约 §7.6）：name 缺省会 SQL 500——前端 rules 兜底；若后端上 Bean Validation，契约同步更新
4. **停用角色语义**（契约 §4 头部）：不进 /role/list 下拉、登录权限聚合排除（重新登录生效）、在线会话快照不回收——将来"停用立即生效"需求属后端改造
5. **菜单树含停用菜单且无 status 出参**（契约 §5.1）：菜单管理页需求时后端需扩展出参或过滤
6. **e2e harness 已抽 lib/**：第三个功能接入直接复用；场景脚本与功能代码同一 commit（技能纪律）
7. 按钮级权限仍前端全显 + 403 兜底（契约 §7.1 既有缺口，待 /me 类接口）
8. 分配菜单弹窗的树勾选语义（回显叶子过滤/提交含半选父）是 EP 组件行为的适配约定——若后续换树实现或后端改存"仅叶子"，此处需重新对齐契约 §4.6/§4.7
