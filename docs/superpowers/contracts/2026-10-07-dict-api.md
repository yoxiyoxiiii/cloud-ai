## 1. 域语义（字典域特有，其余见 pilot §1）

- **两级模型**：`sys_dict_type`（字典类型：dict_name 展示名 + dict_key 程序键）→ `sys_dict_data`（字典项：label 展示标签 + value 存库值）；项经 `typeId`（数值 id）归属类型——**dict_key 不冗余进项表**，改名不破坏归属（设计 D1）
- **dict_key 语义**：全库唯一的程序键（如 `user_status`），消费方按它取数；**可修改**（roleKey 同款，改键触发唯一性校验排除自身）；格式（字母开头、字母数字下划线）为**前端约定，后端不校验**（§6 宽松语义）
- **value 语义**：存库值（如 `"0"`/`"male"`），**同类型内唯一**（uk_type_value，墓碑占键）；跨类型可重复；label 不唯一（展示文案，重复无程序危害）
- **status 语义**：两级各自 `0=正常 1=停用`（实体嵌套 StatusEnum）；**管理端点不过滤停用**（管理页须看全量，靠 tag 区分）——"停用类型/停用项不参与消费取数"属下轮消费端点语义，本轮无消费方
- **排序语义**：类型分页按 `id DESC`（新类型置首，role/user 同款）；项分页按 `sort ASC, id ASC`（sort 是项的展示序，字典的本职）
- **权限快照时效**（沿用 v2 §1 / menu-nav §3，两端与 e2e 共同遵守）：种子落库后 admin **导航刷新即见**（实时）但**操作须重新登录**（快照）——e2e 每脚本新登录天然满足；不做"改完立即可用"断言
- **删除语义**：**禁删有项的类型**（3011，镜像菜单 3005"先删子级"）；不做级联逻辑删（设计 D5）；删除 = 逻辑删除（deleted=1 + update 审计两值），墓碑永久占 dict_key / (typeId,value)（重建同键得 3009/3012，role 域同款现状）

## 2. 类型端点（/system/dict/type）

### 2.1 类型分页 `GET /system/dict/type/page`

- 权限：`system:dict:list`
- 入参（query）：`pageNum` number 默认 1 / `pageSize` number 默认 10（PageQuery，无搜索参数——契约现状）
- 行为：全量未删除类型（含停用），`ORDER BY id DESC`；分页插件 maxLimit 200
- 返回 `R<PageResult<SysDictTypeVo>>`——total 为字符串（Long→String，前端 `Number()`），rows 字段见 §4.1
- 错误码：401/403（通用）

### 2.2 新增类型 `POST /system/dict/type`

- 权限：`system:dict:add`
- 入参（JSON body，DictTypeSaveRequest——**DTO 接参**，超集字段 Jackson 忽略不落库）：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| dictName | string | 是（非空白，否则 1002） | 字典名称（DDL VARCHAR(30)） | `"用户状态"` |
| dictKey | string | 是（非空白，否则 1002） | 字典键（DDL VARCHAR(50)，库级唯一）；格式不校验（前端 pattern 兜底） | `"user_status"` |
| status | number | 否（null 落库默认 0） | 0 正常 / 1 停用 | `0` |

- 行为：dictName/dictKey 非空白校验 → dictKey 查重（deleted=0 口径）→ 审计四值显式写入（createBy/createTime=当前账号/now，update 值 = create 值）→ `DuplicateKeyException` 兜底转 3009
- 返回 `R<Long>`——data 为**新类型 id 字符串**（如 `"1"`）
- 错误码：1002 字典名称不能为空 / 字典键不能为空 / 3009 字典键已存在: {dictKey}

### 2.3 修改类型 `PUT /system/dict/type`

- 权限：`system:dict:edit`
- 入参（JSON body，同 2.2 字段集 + id；**部分更新语义：null 不更新该列**）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 目标类型 id（不存在或已删 → 3008） |
| dictName | string | **空白串拦截** | `""`/纯空白 → 1002；null 不更新；正常值更新 |
| dictKey | string | 同上 | 同上；**改键触发唯一性校验（排除自身）** → 3009 |
| status | number | 否（null 不更新） | 0/1 |

- 行为：requireType(3008) → 空白校验(1002) → 查重(3009) → 动态更新非空列 + updateBy/updateTime（createBy/createTime 不变）→ DuplicateKey 兜底 3009
- 返回 `R<Void>`
- 错误码：3008 / 3009 / 1002（同 2.2 文案）
- 前端消费：**是**（编辑弹窗全量提交三写字段 + id，规避部分更新歧义）

### 2.4 删除类型 `DELETE /system/dict/type/{id}`

- 权限：`system:dict:remove`
- 入参：路径参数 `id`（string 数字，显式命名 `@PathVariable("id")`）
- 行为：requireType(3008) → count 该类型未删项 >0 → **3011 禁删**；否则逻辑删除（deleted=1 + update 审计两值）。**无级联、无种子保护**（字典无种子数据）；count-then-delete 的理论 TOCTOU 窗口接受（§6）
- 返回 `R<Void>`
- 错误码：3008 字典类型不存在 / 3011 该字典类型下存在字典项，先删除字典项
- 前端消费：**是**（确认框文案含类型名；3011 由拦截器 toast，表格刷新对齐）

## 3. 项端点（/system/dict/data）

### 3.1 项分页 `GET /system/dict/data/page`

- 权限：`system:dict:list`
- 入参（query）：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| typeId | string | 是（缺失/空 → 1002） | 所属类型 id（Long→String）；类型不存在或已删 → 3008 | `"1"` |
| pageNum | number | 否（默认 1） | 页码 | `1` |
| pageSize | number | 否（默认 10） | 页大小 | `10` |

- 行为：typeId 非空校验 → 类型存在性校验（3008）→ 该类型全部未删项（含停用），`ORDER BY sort ASC, id ASC`
- 返回 `R<PageResult<SysDictDataVo>>`（total 字符串，rows 见 §4.2）
- 错误码：1002 类型不能为空 / 3008 / 401 / 403
- 设计注：typeId 存在性校验使"类型在他处被删后刷新"得到明确 3008 toast 而非静默空表（与 role listMenuIds 的宽松口径不同，此处从严——页面联动需要）

### 3.2 新增项 `POST /system/dict/data`

- 权限：`system:dict:add`
- 入参（JSON body，DictDataSaveRequest）：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| typeId | string | 是（缺失 → 1002；类型不存在/已删 → 3008） | 归属类型 id | `"1"` |
| label | string | 是（非空白，否则 1002） | 展示标签（DDL VARCHAR(50)，类型内不唯一） | `"启用"` |
| value | string | 是（非空白，否则 1002） | 存库值（DDL VARCHAR(50)），**同类型内唯一**；格式不校验（前端 pattern 兜底） | `"0"` |
| sort | number | 否（null 落库默认 0） | 排序号 | `1` |
| status | number | 否（null 落库默认 0） | 0/1 | `0` |

- 行为：typeId/label/value 校验 → 类型存在性(3008) → (typeId,value) 查重 → 审计四值写入 → DuplicateKey 兜底 3012
- 返回 `R<Long>`——新项 id 字符串
- 错误码：1002（类型不能为空/标签不能为空/字典值不能为空）/ 3008 / 3012

### 3.3 修改项 `PUT /system/dict/data`

- 权限：`system:dict:edit`
- 入参（JSON body，同 3.2 字段集 + id；**部分更新语义：null 不更新**）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 目标项 id（不存在或已删 → 3010） |
| typeId | string | 否（null 不更新） | 变更时校验目标类型存在（3008）并按新类型查重 value；**项可在类型间迁移**（管理面少用，API 能力保留） |
| label | string | **空白串拦截**（1002） | null 不更新 |
| value | string | 同上 | 同上；(生效 typeId, value) 查重排除自身 → 3012（生效 typeId = 本次传入 ?? 库中现值） |
| sort / status | number | 否（null 不更新） | — |

- 行为：requireData(3010) → 空白校验(1002) → typeId 变更校验(3008) → 查重(3012) → 动态更新 + updateBy/updateTime → DuplicateKey 兜底 3012
- 返回 `R<Void>`
- 错误码：3010 / 3008 / 3012 / 1002
- 前端消费：**是**（编辑弹窗全量提交五写字段 + id，typeId 亦提交）

### 3.4 删除项 `DELETE /system/dict/data/{id}`

- 权限：`system:dict:remove`
- 入参：路径参数 `id`（显式命名）
- 行为：requireData(3010) → 逻辑删除（deleted=1 + update 审计两值）。**不校验所属类型是否存活**（可删除已死类型的遗留项——数据治理入口，§6）；墓碑占 (typeId,value)
- 返回 `R<Void>`
- 错误码：3010 字典项不存在

## 5. 错误码汇总与占位声明（**本节为 3xxx 段分配的现行权威**）

| code | 含义 | 出现端点 |
|---|---|---|
| 200 | 成功 | — |
| 401 | 未认证（HTTP 真实 401，网关） | 全部 |
| 403 | 无操作权限（HTTP 200 + body 403） | 全部（@PreAuthorize） |
| 1002 | 字典名称不能为空 / 字典键不能为空 / 类型不能为空 / 标签不能为空 / 字典值不能为空 | POST/PUT 类型与项、项分页 |
| 3008 | 字典类型不存在（含已删）: {id} | PUT/DELETE 类型；项三端点的 typeId 校验 |
| 3009 | 字典键已存在: {dictKey} | POST/PUT 类型 |
| 3010 | 字典项不存在（含已删）: {id} | PUT/DELETE 项 |
| 3011 | 该字典类型下存在字典项，先删除字典项 | DELETE 类型 |
| 3012 | 该类型下字典项值已存在: {value} | POST/PUT 项 |

**占位声明重排（声明性取代 menu-management v2 §5 末行 / menu-nav §4 / perms-api §2 的"3008 起预留"）**：字典域占用 3008-3012；**3013 起预留给 backlog「内置角色/菜单保护」另案**（该另案与本域如有并行，3008-3012 归字典所有，另案从 3013 接续）。

## 6. 宽松语义清单（如实记录，前端以约定兜底，不因契约掩盖）

1. **dictKey/value 无格式校验**：字母开头/字符集白名单为前端 pattern 约定（同 menu perms 口径）；脏值入库合法，属数据治理
2. **label 类型内不唯一**：重复标签可入库（展示文案，无程序危害）；唯一性仅约束 value
3. **墓碑占键**：逻辑删除的类型/项永久占 dict_key / (typeId,value)——重建同键恒 3009/3012（uk_account/uk_role_key 同款现状）；物理清理另案
4. **PUT 部分更新语义**：null 不更新（空白串仅 dictName/dictKey/label/value 拦截）；前端全量提交写字段规避
5. **删除无级联**：删类型遇 3011 手动清项；**无种子保护**（字典无种子数据，admin 删光字典不影响系统功能——与菜单域不同，无保护另案诉求）
6. **TOCTOU 窗口**：删类型的 count-then-delete、查重-then-insert 均有理论竞态（后者由 DuplicateKey 兜底；前者接受，菜单 3005 同口径）
7. **项操作不校验所属类型存活**：PUT/DELETE 项只查项自身（3010）——可治理"类型已死项未清"的遗留数据（§3.4）
8. **DTO 超集忽略**：body 中 id（POST）/审计/deleted 等超集字段 Jackson 反序列化后不落库（无对应写列）
