# 数据权限列处理注解化 API 契约（轻量修订式：wire 零变更 + 错误码 3042 增补）

- 日期：2026-10-12
- 状态：**定稿**——架构-agent 出品；设计 `docs/superpowers/specs/2026-10-12-dataperm-column-advisor-design.md`（D51-D58）、计划 `docs/superpowers/plans/2026-10-12-dataperm-column-advisor.md`
- **契约形态说明**：本轮 wire 面（请求/响应 JSON 结构）**零变更**——列隐藏仍是「字段置 null」、脱敏仍是整值 `***`（拍板③），唯一对外可观测变化是**新错误码 3042**（服务端缺陷显性化的 fail-closed 拒绝）。故不重述既有端点全文，出**修订式轻量契约**：以本文件声明既有承诺不变 + 增补 3042 语义。理由：3042 是用户可观测的对外承诺（前端拦截器通用 toast 链会展示其文案），契约体系须有记载；wire 无变化部分重述反而制造双源漂移面。

## 1. 既有承诺不变声明（冻结基线）

以下契约的全部承诺**逐条不变**，仍为行为对齐基线：

- `2026-10-10-data-permission-api.md`：数据权限域 9 端点 + my-scope + leave 两端点语义；§2 术语「列动作 0 隐藏（VO 字段置 null）/ 1 脱敏（整值替换 `***`）」；§8 错误码 3026-3034；列元信息 resources 接口形状
- `2026-10-11-dataperm-predicate-api.md` / `2026-10-11-dataperm-operators-api.md`：行级条件谓词与操作符域（本轮零触碰）

具体到列输出形态的冻结点（本轮重申）：

| 场景 | wire 形态（不变） |
|---|---|
| 列隐藏（action=0） | 字段**存在于 JSON、值为 null**（如 `"title": null`）——非字段省略 |
| 列脱敏（action=1） | 字段值为整值 `"***"`（null 值列脱敏保持 null） |
| 无列动作 | 原值 |
| columnSummary / 留痕 / my-scope | 格式与取值口径不变（D28 三处冻结点） |

实现机制变化（Service 手工 applier → advice 统一应用）对前端**完全透明**——响应 JSON 逐字节一致，前端 TS 类型、组件、e2e JSON 断言零维护。

## 2. 错误码增补：3042

| code | 文案 | 触发条件 | 消费方行为 |
|---|---|---|---|
| 3042 | 数据权限列处理异常，响应已拒绝 | 响应树中出现数据权限列载体 VO，但该请求的列处理上下文缺失（服务端接线缺陷——Service 求值后未声明上下文），或列应用链路异常。**fail-closed 语义：响应 data 不返回（整体拒绝），不降级为明文** | HTTP 200 + body code=3042，走拦截器通用 toast 链（无需特判分支）；出现即服务端缺陷，应反馈开发排查（服务端已 log.error 定位到方法/URI） |

- 分段：system 段（3xxx）；账本：R9 死信治理轮已占用 3038-3041，本轮自 3042 接续
- 非用户操作可触发（正常配置/使用不会出现）；联调/测试环境出现 3042 = 对应读路径漏接 `DataPermColumnContext.set`，按服务端缺陷处理
- 与 3026（无权访问该数据，行级拒绝）语义区分：3026 = 用户权限不足的正常业务拒绝；3042 = 服务端缺陷的防御性拒绝（fail-closed 护栏触发）
